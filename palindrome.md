# Palindrome Checker (C++ & Python)

A simple repository containing implementation codes in **C++** and **Python** to check whether a given number or string is a **Palindrome** or not.

---

## 🚀 Features

* **Dual Language Support:** Code is available in both C++ and Python.
* **Easy to Run:** Uses clean and simple logic that is easy to understand and execute.

---

## 📂 Project Structure

* `main.cpp` - C++ program to check for a palindrome.
* `main.py` - Python program to check for a palindrome.
