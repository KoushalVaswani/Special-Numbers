# Special Numbers: Armstrong Number Checker

This repository contains implementations to check whether a given number is an **Armstrong Number** (also known as a Narcissistic Number) using different programming languages.

---

## 🧐 What is an Armstrong Number?

An **Armstrong number** of order $n$ (number of digits) is a number that is equal to the sum of its own digits each raised to the power of $n$.

### Example:
*   **153** (Order = 3 digits):  
    $$1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153$$  
    *(Hence, 153 is an Armstrong number)*
    
*   **1634** (Order = 4 digits):  
    $$1^4 + 6^4 + 3^4 + 4^4 = 1 + 1296 + 81 + 256 = 1634$$  
    *(Hence, 1634 is an Armstrong number)*
